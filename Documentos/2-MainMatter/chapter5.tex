\section{Validation of Research Hypotheses}
\label{sec:hypothesis_validation}

This section reviews the experimental findings against the four research hypotheses defined in \Cref{sec:research_problems}.

\subsection{Hypothesis 1: Setup Time Reduction}
\label{sec:val_rh1}
The results in \Cref{sec:eval_setup_time} show that the wizard reduced total configuration time from 155.0~minutes (manual creation) to 29.5~minutes, representing an 81.0\% reduction in engineering effort. Interactive 3D raycasting eliminated the need to measure coordinates by hand, while automated validation prevented syntax errors in submodels. These findings validate \textbf{RH1}, confirming that a guided, model-driven workflow significantly speeds up \gls{DT} deployment.

\subsection{Hypothesis 2: Semantic Interoperability and Decoupling}
\label{sec:val_rh2}
By using the standardized \gls{AAS} (IEC~63278) with five modular submodels, all geometric, kinematic, and behavioral properties were stored in self-contained packages. The Unity runtime imported and built complete 3D simulation scenes directly from these packages without requiring pre-made scenes or proprietary plugins. This validates \textbf{RH2}, showing that \glspl{DT} can be decoupled from specific game engines and simulation tools.

\subsection{Hypothesis 3: Real-Time Synchronization and Drift Correction}
\label{sec:val_rh3}
The latency benchmarks in \Cref{sec:eval_latency} confirmed the effectiveness of the dual-channel design. The dedicated \gls{TCP} socket delivered physical sensor events to the simulation with an average latency of 5.4\,ms ($\sigma = 1.1\,$ms), compared to 182.4\,ms for \gls{REST} polling. Combined with the position-snapping technique, this eliminated accumulated drift between the physical bench and the virtual simulation, validating \textbf{RH3}.

\subsection{Hypothesis 4: Autonomous \gls{VC}}
\label{sec:val_rh4}
In Mode~A, the simulation executed closed-loop conveyor logic entirely in software. The built-in rule engine read event rules from the \texttt{ControlLogic} submodel and actuated virtual diverters and stops reliably without connecting to a physical \gls{PLC} or network controller. This confirms \textbf{RH4}, demonstrating that control sequences can be tested before hardware is installed.
